# Kikkake

東京で「やってみたい」を世代を越えた仲間と実現する体験コミュニティーの操作試作品です。[仕様書](docs/仕様書.md)を基に作成しています。

## クラウドで開発する

Node.js 24 / npm 11。Codexの既存の `/workspace/kikkake` チェックアウトを使います。

```sh
cd /workspace/kikkake
npm ci
npm run dev -- --port 5173
```

検証: `npm test`、`npm run build`。本番用ファイルは `dist/` に生成されます。

## 試せる流れ

チュートリアル → 企画一覧 → 詳細 → 申請入力 → 内容確認 → 申請確定。マイページでデモ利用者を投稿者に切り替えると承認できます。別の利用者からも申し込み、投稿者を含め3人を承認すると日時相談へ進めます。企画投稿、グループチャット、開催内容入力、各参加者の内容確認、開催24時間前までの運営申請、デモ運営による承認を試せます。通知とデータはブラウザ内に保存します。

## 現段階の範囲

実際のログイン・本人確認・バックエンド・利用者間の通信はありません。デモの利用者・運営切り替えは認証ではありません。個人情報を入力しないでください。個人チャット、申請編集、保留・見送り、画像送信、メール、ブロック、実際の通報受付、管理画面、アンケートなどは今後の実装です。PWA用マニフェストを同梱していますが、オフラインキャッシュは未実装です。正式公開する際はデータベース、認証、サーバーでの権限・安全ルール検証が必要です。

このリポジトリは動画生成用スクリプトを含みません。動画関連の添付ファイルは別用途のためクラウドの添付保存場所に保持しています。
